# ATELIER 02 · 视觉重构记录

这次交付将原版「网格机柜原型」改为「精密流体装置」。重构不改变碰撞、泵预算、关卡和计分。所有宣传式截图都来自交付程序的实际场景，没有将生成图片替换进三维画布。

## 构图和视觉语言

主画面使用深松绿摄影棚、暖白瓷釉底座、冷钛金属与少量香槟色接缝。四种液体分别为青绿、琥珀、浅蓝和玫紫。除颜色以外，端口和操作面板仍使用 A/B/C/D 区分回路。

首页从左侧文字引导到右侧装置，去掉旧版把模型关在圆角卡片里的布局。游戏中保留左右操作区，模型居中；展示模式移除游戏面板，让装置成为唯一主体。手机使用纵向布局，避免为塞进一个屏幕而缩小布线格。手机端导航保留关卡、工坊和每日入口。

暗背景没有靠泛光遮掩细节。基础舞台的渐变和接触阴影只承担空间定位；没有额外的炫光、色差或漂浮粒子。

在大面积瓷釉面和框架倒角上，改用连续法线，修复 ExtrudeGeometry 面法线造成的折面高光。很小、在常规视距只有几个像素的刻痕和夹片使用更低面数。几何精度按实际尺寸分配，不是把全部零件都机械地拉到同一个细分等级。

## 材质和光照

GPU 路径配置了程序化摄影棚环境、PMREM、暖主光、冷填光和后缘光。材质分别设置金属度、粗糙度、微表面法线、清漆、透射、厚度及折射率。微表面纹理来自项目内的确定性程序生成，不依赖在线贴图。

CPU 路径不是这些 GPU 功能的替代验收。它使用项目新写的 C/WASM 光栅内核，计算插值法线、近似反射高光、深度遮挡、透明混合和真实深度阴影图。玻璃在 CPU 中是受控透明近似，不是物理折射；仪表和标签使用真实纹理采样。

CPU 原版的平面着色与简单投影已替换，不再用「有 GPU 后会更漂亮」作为当前画面检查的依据。实际交付截图就是 CPU 版本当前能输出的画面。

仪表上的 0.84、SYSTEM / 084 等是装置视觉标签，不表示压力、扬程或物理流量。游戏依旧是离散路径与泵额度规则，不提供真实水力学计算。

## 运动与交互

镜头切换同时平滑改变角度、缩放和观察中心；拖动释放有阻尼。主动环视不是固定匀速绕圈，速度缓慢变化，俯仰也有轻微起伏。减少动态效果关闭这些装饰性运动，不影响实际试运行状态。

展示模式支持键盘焦点约束、Esc 退出、恢复原控件焦点，以及只读三维观察。隐藏布线面板后，点击模型或按方向键不会误铺管。双指缩放使用真实 Pointer Events，并经过双触点浏览器输入测试。

截图按钮导出当前真实机柜画面与小型版式信息。CPU 拍照先重绘高精度帧，平时的动态分辨率不会直接决定导出清晰度。

## 本次观察与修复循环

第一次重建后的检查发现光影仍平、底座和 UI 的主次不统一，随后重做了深色场景与版式。

第二轮检查发现悬空设备、框架细线锯齿和重复法兰，补上安装轨道，调整高精度采样并减少冗余接头。

特写检查发现底座倒角有可见折面，重新计算连续法线，并增加弯管采样、储液罐的方向性穿壁接头和设备夹片。

交互复查发现展示模式需要隔离游戏输入，手机入口不能因隐藏导航而丢失，桌面装饰渐变还导致横向溢出。这些问题均已修复并加入或执行对应回归。

最后一轮加入静帧缓存、运动时的像素预算和高精度拍照重绘，在不降低交付截图精度的前提下降低 CPU 动态成本；同时验证剖层、重复切关、旧版存档恢复和最大工坊配置。

早期观察帧保存在 `artifacts/iterations/`。最终画面和逐项测试记录位于 `artifacts/`，本轮验收汇总位于 `docs/QA_REPORT.md`。
