# 自定义关卡格式

从“自由实验 → 导入关卡”选择 JSON。完整示例：`examples/cross-layer.json`。

```json
{
  "id": "my-level",
  "name": "示例实验",
  "subtitle": "MY EXPERIMENT",
  "tip": "连接同字母端口。",
  "size": 3,
  "height": 2,
  "gravity": false,
  "pumps": 0,
  "chapter": 0,
  "blocks": [[1, 0, 1]],
  "circuits": [{"start": [0, 0, 0], "end": [2, 0, 0]}],
  "solution": [[[0, 0, 0], [1, 0, 0], [2, 0, 0]]]
}
```

坐标 `[x,y,z]` 都必须是整数，x/z 小于 size，y 小于 height。size 范围 3–7，height 范围 2–5，回路数 1–4。工坊界面只提供 4–7 格和 2–4 回路，但导入验证器允许更简单的教学关。

每个入口、出口和障碍必须唯一且在界内。`solution` 的元素顺序与 circuits 相同；从对应入口开始、出口结束，六方向逐格相邻，所有路线之间和障碍不能重叠。重力模式下参考路线所有上升边总数不得超过 pumps。par 会由验证器重新计算，不能通过导入字段伪造。

回路字母会被重新分配为 A、B、C、D。导入后使用独立关卡 ID，不污染固定章节成绩。文件最大 200 KB，超过限制直接拒绝。当前导入要求提供参考解；没有自动求解任意用户图形的关卡编辑器。
