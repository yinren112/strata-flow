## 测试环境与边界

浏览器：Chromium 144.0.7559.96 built on Debian GNU/Linux 13 (trixie)

Node：v22.16.0

本环境实际渲染后端：wasm-studio。WebGL 探测：{"webgl2":false,"wasm":true}。

浏览器以 set_content 加载交付 HTML 的完整内容。没有使用替代 UI；但这种加载方式不验证 HTTP 来源、file:// 导航、PWA 缓存或浏览器原生存储。存储流程使用明确的 Storage 测试替身；另外测试了真实存储不可用时显示提示并继续游玩的路径。

手机和双触点用例为 Chromium 视口与输入模拟，不是真实 iPhone、Android 或 iPad 的验收。

Node 测试实际启动本地静态服务并请求主页和资源，检查 HTTP、MIME、HEAD、404、405、路径越界处理。这与浏览器能否在目标设备上打开该来源是两项不同检查。
